# 🐾 重生之我在地球给臭乐乐当厨师

这是一个专为**臭乐乐**打造的温馨粉色点餐微信小程序。臭乐乐在手机上挑选想吃的家常菜直接下单，大厨掌勺端实时接收订单；点击每个菜品即可查看详细配料清单、调料比例与制作步骤。

---

## ✨ 核心特色与功能设计

### 1. 🐱 温馨粉色视觉风格
- **舒适粉色调**：以甜美柔和的樱花粉（`#FF527B`、`#FFF7F9`、`#FFE4EC`）为主色调，温馨干净。
- **自然温馨文风**：彻底去除油腻浮夸字眼，语言自然舒适，保留甜蜜温馨感。
- **专属点餐身份**：默认女朋友身份为“臭乐乐”，专属点餐篮与做餐进度追踪。

### 2. 📱 权限与界面隔离（点餐端 vs 掌勺端）
- **女朋友端轻量纯粹**：
  - 底部只保留【点餐】和【做餐进度】两个选项卡。
  - 臭乐乐只能看到点菜与做菜进度，看不到厨房接单和菜谱管理，避免剧透与干扰。
- **掌勺端独立管理**：
  - 点击点餐界面右上方设备胶囊，内嵌专属暗门（默认暗号：`0906`）。
  - 输入暗号后解锁【掌勺接单台】与【菜谱管理】，独立接单、修改配方与查看步骤。

### 3. 🍲 全时段五大餐别分类（支持替换真实美食图片）
- **🥣 营养早餐**：爱心溏心蛋葱油拌面、暖胃元气皮蛋瘦肉粥、滑嫩水蒸蛋等。
- **🥗 精致午餐**：农家小炒肉、番茄炒鸡蛋、蒜蓉炒菜心等经典下饭菜。
- **🍲 丰盛晚餐**：可乐鸡翅、清蒸鲈鱼、肉末嫩豆腐等荤素搭配大餐。
- **🥣 暖心靓汤**：玉米排骨汤、浓醇番茄牛腩汤等温润靓汤。
- **🍢 宵夜时光**：蒜蓉粉丝蒸虾、治愈金沙蛋炒饭、孜然炒牛肉等追剧夜宵。
- **真实图片替换支持**：每个菜品数据包含 `image` 字段，可直接将真实拍照放入 `miniprogram/images/dishes/` 并填入路径；若未传图片自动优雅展示对应美食 Emoji。

### 4. 👨‍🍳 掌勺大厨接单台（实时接单 & 一键看配料步骤）
- **新订单实时提醒**：臭乐乐提交点餐后，掌勺手机实时收到提醒与弹窗。
- **一键查看配料与步骤**：
  - 订单中点击**【📖 查看配料步骤】**即可滑出详细制作抽屉：
    - **🥦 食材与配料**：精准用量克数、切配要点。
    - **🧂 调味料配比**：生抽、老抽、糖、盐等勺数与克数。
    - **🍳 做菜步骤与计时器**：支持步骤火候倒计时，精准把握烹饪时间。
- **状态全流程推进**：已点单 ➔ 备料中 ➔ 热炒中 ➔ 端上桌 ➔ 用餐完毕。

### 5. 💌 贴心口味叮嘱
- 支持选择用餐餐别与期望用餐时间（如：尽快做、半小时后等）。
- 快捷口味标签：`少油少盐`、`微辣`、`不辣`、`不要葱花`、`不要香菜`、`多留点汤汁`等。
- 自定义备注留言。
